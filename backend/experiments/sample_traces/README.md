# Sample traces (synthetic)

The two CSV files here are **synthetic**: generated by `make_synthetic.py`
(seeded) to match the column layout of

- Google cluster-data 2011, `task_events` table (13 columns, timestamps in µs)
- Alibaba cluster-trace-v2018, `batch_task.csv` (9 columns, times in seconds)

They exist for tests and dashboard demos and contain no real trace data.
To use a real trace, download it from the publisher and import a
`task_events` part file or `batch_task.csv` through the dashboard's
**Import trace** button or `backend/experiments/trace_import.py`.
